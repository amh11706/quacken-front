# Contributing

Bug reports, fixes and new features are all welcome.

## Before you start

- Setup is in the [README](README.md).
- For anything bigger than a small fix, open an issue first so we can agree on
  the approach before you spend time on it.
- Changes that also need server support go in
  [quackgo](https://github.com/amh11706/quackgo) as a separate pull request.
  quackgo has its own license and contribution terms, so read its
  CONTRIBUTING.md before contributing there.

## Pull requests

- `npm run lint` and `npm run build` should pass.
- Keep each pull request to one change.
- For visible changes, a screenshot or short clip in the pull request helps.
